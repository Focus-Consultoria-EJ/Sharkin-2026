# Services

### Funcionalidades para usuário

- O sistema deve ser capaz de fazer autenticação do usuário via email e senha
- O sistema deve permitir que um usuário troque sua senha
- O sistema deve ser capaz de registrar o data e hora do plantão mediante a solicitação do usuário
- O sistema deve ser capaz de fazer alteração de dados do usuário como foto de perfil e nome

### Funcionalidades do usuário especial GEP

- O sistema deve ser capaz de cadastrar e deletar um usuário
- O sistema deve ser capaz de gerar relatórios personalizados mediante a solicitação do usuário
- O sistema deve ser capaz de buscar pelos dados de um usuário comum pelo seu nome

### Funcionalidades Gerais

- O sistema deve gerar relatórios dos plantões semanalmente, sendo enviados via email para GEP
- O sistema deve registrar no banco de dados data e hora referentes a determinado plantão

# UI

- A interface de usuário deve renderizar uma página diferente para usuários comuns e o usuário GEP
- A interface do usuário deve seguir a paleta de cores da empresa, bem como sua identidade visual
- A princípio, não é necessário se preocupar com responsividade da interface
