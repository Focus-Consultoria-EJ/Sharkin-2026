# Sharkin-2026

O projeto consiste em um sistema para fazer registros de plantão, ou melhor, a reformulação do atualmente utilizado na empresa

## Pré-requisitos

O sistema deve ser rodado localmente, tendo em vista que até o momento não há um domínio na internet para utilizá-lo, então é necessário apenas uma ferramenta: o **git** e o **docker** instalados na máquina

## Instalação e execução

Copie a url do repositório do jeito que preferir (https, ssh, githubCLI), execute `git clone URL` na pasta que vai se localizar o projeto, sem seguida, na pasta raiz do projeto execute `docker compose up` (se tiver utilizando o linux rode o comando com privilégios sudo), por fim acessa o navegador na url: `localhost:3000`
